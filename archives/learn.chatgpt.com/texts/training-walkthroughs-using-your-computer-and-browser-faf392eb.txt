Using your computer and browser

ChatGPT can read what’s on screen, click, and type in apps and websites you allow it to use. Work through a spreadsheet, research a topic across websites, or fill out a form on a site you’re already signed in to.

Use Computer, Browser, or Chrome

Type @ in a chat to choose one of these plugins.

Computer

ChatGPT can navigate desktop apps, read information, and use their controls. For example, it can find categories that are over budget in a Numbers spreadsheet, change an app setting, or start a playlist in Spotify.

Browser

Research a topic or compare sources in the browser inside the ChatGPT desktop app. You can also open a site ChatGPT is building and leave feedback on the page.

Chrome

Let ChatGPT work in your regular Chrome browser, including sites where you’re already signed in. It can start a new tab, read an internal dashboard, use page controls, or fill out a form.

When to use plugins vs. Computer, Browser, or Chrome

Use a dedicated plugin when it can do the job directly, such as searching Gmail, reading a calendar, or sending a message in Slack. Use @Computer, @Browser, or @Chrome when you need the app or website’s interface. For example, you can check a visual layout, use a control, or work in a service without a matching plugin. Learn more about plugins and skills.

Get set up

In the ChatGPT desktop app, select ChatGPT, choose Work, and open Plugins. Install Computer Use for desktop apps, Browser for the built-in browser, or Chrome for your regular browser. Follow the setup steps for the plugin you need.

Browser is built into the ChatGPT desktop app. Open it from the toolbar after installing the plugin. On macOS, Computer Use needs Screen Recording and Accessibility permissions. For Chrome, install the browser extension and approve its permissions when prompted. Keep Work locally selected when the task needs apps or files on your computer.

Share an app window with Appshots

An Appshot attaches your frontmost Mac window to a chat. It includes a screenshot and any text the app makes available.

Bring the window you want to share forward and press both Command keys (⌘ + ⌘). This takes a real Appshot. Use it when an error, spreadsheet, design, or settings screen is easier to share than describe.

For example, take an Appshot of a Slack thread and ask, “What’s going on here? What was decided, what’s still open, and do I need to respond?”

Find earlier work with Computer History

An Appshot shares what’s on screen now. Computer History can help ChatGPT recall earlier work from the apps and websites you choose to include, after you turn it on.

For example, ask, “Find the planning document I was working on yesterday.” It can only use the activity it captured, not everything you have ever done on your computer.

Use ChatGPT inside Chrome

Open ChatGPT from Chrome’s toolbar or Extensions menu. The chat opens beside the page you’re viewing, so you can ask about it without copying everything into a new conversation.

Ask ChatGPT to explain a chart or compare this week’s dashboard numbers with last week’s. It can also work on the page: change filters, open a report, or fill out a form.

Manage app and website access

In the ChatGPT desktop app, open Settings > Computer use to choose which desktop apps ChatGPT can use. Select Manage next to Chrome to review allowed websites, and check Always-allowed apps to remove access you no longer need.

For websites in the built-in browser, manage access in Settings > Browser.
