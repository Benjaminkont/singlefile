# 文件结构说明

公开仓库包含精选的 82 篇原文、2 份中文副本和 82 份正文。抓取报告只覆盖这批原文；下表中的运行产物目录按需生成，不随本次发布上传。

| 位置 | 职责 |
| --- | --- |
| `archives/index.html` | 所有站点的统一浏览首页 |
| `archives/<站点>/index.html` | 单个站点的浏览目录 |
| `archives/<站点>/pages/` | 自包含网页 HTML；同站点页面保留相对链接 |
| `archives/<站点>/texts/` | 归档时提取的正文 |
| `archives/<站点>/records/` | 抓取、验证、发现等运行记录 |
| `config/sources/<站点>.json` | 该站点的显示名、origin 和 targets；目标含 url、file，可含 title、aliases |
| `run/` | 可双击的三个 Mac 入口，内部调用通用脚本 |
| `scripts/` | 共享路径配置、浏览器选择、抓取、验证、链接整理、目录生成及预览 |
| `tests/` | 使用临时目录的回归测试，不改动正式资料 |
| `tests/.artifacts/browser/` | 显式运行浏览器验收时生成的截图和结果 |
| `docs/官方资料/` | 固定版本的 SingleFile 官方资料和原始来源说明 |
| `.browser-cache/`、`node_modules/` | 浏览器缓存和工具依赖 |

## 检查资料

正式归档和各站点的运行记录均保存在 `archives/`。查看抓取结果使用对应站点的 `records/reports/`；验证离线阅读或运行回归测试：

```bash
npm run verify -- --source=anthropic.com
npm test
```

浏览器验收的截图和结果可以重新生成，不参与归档目录展示。网页快照需要更新时显式使用 `--refresh`；仅更新目录不会改写已有快照。
