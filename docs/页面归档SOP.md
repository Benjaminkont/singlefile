# 页面归档流程

1. 打开原始网页，确认要保存的内容已能正常访问。
2. 双击 `run/添加网页.command`，粘贴完整网址并按回车。也可运行 `npm run add -- '网址'`。
3. 等待 `SAVED` 和目录更新提示。若显示失败，检查该站点 `records/logs/` 和 `records/reports/`；任务会保留失败记录，不把它列为可阅读资料。
4. 双击 `run/打开资料库.command`，搜索标题或网址，点击查看正文、图片和排版。静态保存不能保证视频和交互功能可用。

重复添加已有成功网址会直接复用；确实需要更新时在终端增加 `--refresh`。保存失败不会用失败页面覆盖先前成功的快照。

添加过程自动完成站点配置、唯一文件名、HTML、正文、元数据、日志、离线检查和目录登记，不再手工编辑历史样本清单。新网页的文件名由网址路径和短哈希生成；旧资料保留原文件名。

只调整目录显示名称时，修改 `config/sources/<站点>.json` 中的 `name`，然后双击“更新目录”。不要直接编辑生成的 index.html。

批量收集和高级选项见 [使用指南](README.md)。
