single-file [url] [output]

Positionals:
  url     URL or path on the filesystem of the page to save  [string]
  output  Output filename  [string]

Options:
  * Browser Configuration:
    --browser-server: Server to connect to <string> 
    --browser-headless: Run the browser in headless mode <boolean> (default: true)
    --browser-executable-path: Path to chrome/chromium executable <string> 
    --browser-engine: Browser engine to use (chromium, firefox). Firefox is driven through WebDriver BiDi and has limitations: --create-browser-profile is not available, --browser-mobile-emulation only sets the viewport size and scale factor, --emulate-media-feature and the pause of --browser-debug are ignored, the requests of service workers do not get the blocked URL patterns and extra HTTP headers, and navigator.webdriver is true in the page <string> (default: "chromium")
    --browser-profile: Path of the browser profile directory to use, e.g. to save pages requiring a logged-in session (see --create-browser-profile). The directory is copied before starting the browser and is left unmodified. <string> 
    --browser-width: Width of the browser viewport in pixels <number> (default: 1280)
    --browser-height: Height of the browser viewport in pixels <number> (default: 720)
    --browser-debug: Enable debug mode <boolean> 
    --browser-arg: Argument passed to the browser <string*> 
    --browser-args: Arguments provided as a JSON array and passed to the browser <string> 
    --browser-single-process: Run the browser as a single process (enabled by default on Windows only, where it applies only to Google Chrome since other browsers exit in this mode, current browsers on other platforms do not support this mode) <boolean> (default: false)
    --browser-start-minimized: Minimize the browser <boolean> 
    --browser-ignore-insecure-certs: Ignore HTTPs errors <boolean> 
    --browser-bypass-csp: Bypass the Content Security Policy of the page, needed to save pages enforcing Trusted Types with browsers based on Chromium 150 or older <boolean> (default: false)

  * Browser Loading & Timing:
    --browser-load-max-time: Maximum delay of time to wait for loading the page in ms <number> (default: 60000)
    --browser-capture-max-time: Maximum delay of time to wait for capturing the page in ms <number> (default: 60000)
    --browser-wait-delay: Time to wait before capturing the page in ms <number> 
    --browser-wait-end-delay: Time to wait after capturing the page in ms <number> 
    --browser-wait-until: When to consider the page is loaded (InteractiveTime, networkIdle, networkAlmostIdle, load, DOMContentLoaded) <string> (default: "networkIdle")
    --browser-wait-until-delay: Delay of time in ms to wait before considering the page is loaded when the value of --browser-wait-until is reached <number> (default: 1000)
    --browser-wait-until-fallback: Stop loading the page and capture it as it is when --browser-load-max-time expires before the value of --browser-wait-until is reached, provided the page has reached DOMContentLoaded; a load timeout error is thrown otherwise <boolean> (default: true)

  * Device Emulation:
    --browser-mobile-emulation: Emulate a mobile device <boolean> 
    --browser-device-width: Width of the device viewport in pixels (default value is 360 when using --browser-mobile-emulation) <number> 
    --browser-device-height: Height of the device viewport in pixels (default value is 800 when using --browser-mobile-emulation) <number> 
    --browser-device-scale-factor: Scale factor of the device viewport (default value is 2 when using --browser-mobile-emulation) <number> 
    --user-agent: User-agent of the browser <string> 
    --accept-language: Accept language of the browser <string> 
    --platform: Platform of the browser (default value is "Android" when using --browser-mobile-emulation) <string> 
    --emulate-media-feature: Emulate a media feature. The syntax is <name>:<value>, e.g. "prefers-color-scheme:dark" <string*> 

  * Network & HTTP:
    --http-header: Extra HTTP header <string*> 
    --http-proxy-server: Proxy address <string> 
    --http-proxy-username: HTTP username <string> 
    --http-proxy-password: HTTP password <string> 
    --accept-header-font: Accept header for fonts <string> (default: "application/font-woff2;q=1.0,application/font-woff;q=0.9,*/*;q=0.8")
    --accept-header-image: Accept header for images <string> (default: "image/avif,image/webp,image/apng,image/svg+xml,image/*,*/*;q=0.8")
    --accept-header-stylesheet: Accept header for stylesheets <string> (default: "text/css,*/*;q=0.1")
    --accept-header-script: Accept header for scripts <string> (default: "*/*")
    --accept-header-document: Accept header for documents <string> (default: "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8")

  * Content Blocking:
    --block-audios: Block audios <boolean> (default: true)
    --block-fonts: Block fonts <boolean> 
    --block-images: Block images <boolean> 
    --block-alternative-images: Block alternative images <boolean> (default: true)
    --block-scripts: Block scripts <boolean> (default: true)
    --block-stylesheets: Block stylesheets <boolean> (default: false)
    --block-videos: Block videos <boolean> (default: true)
    --block-mixed-content: Block active content (i.e. stylesheets, scripts, fonts) served from HTTP in HTTPS pages, like browsers do; images, videos and audios are unaffected <boolean> 
    --blocked-url-pattern: Regular expression matching URLs to block (e.g. 'annoying-banners\.com') <string*> 

  * Resource Loading:
    --load-deferred-content: Load deferred (a.k.a. lazy-loaded) content, i.e. images, frames, and the messages a page unmounts while you scroll <boolean> (default: true)
    --load-deferred-content-dispatch-scroll-event: Dispatch 'scroll' event when loading deferred content <boolean> (default: true)
    --load-deferred-content-max-idle-time: Maximum delay of time to wait for deferred content in ms <number> (default: 1500)
    --load-deferred-content-keep-zoom-level: Keep the page zoomed out while loading deferred content, instead of zooming out only for the moment the page is measured <boolean> 
    --load-deferred-content-before-frames: Load deferred content in frames before saving their contents <boolean> 
    --load-deferred-content-min-zoom-factor: Smallest zoom factor used while loading deferred content, between 0 and 1. The page is zoomed out to make the site believe the whole document is on screen, which also shrinks every measurement the site takes at that moment. Raise this to bound that effect, or set it to 1 to load deferred content without zooming out at all <number> 
    --load-deferred-content-block-cookies: Block access to document.cookie while loading deferred content <boolean> 
    --load-deferred-content-block-storage: Block access to localStorage and indexedDB while loading deferred content <boolean> 
    --max-resource-size-enabled: Enable removal of embedded resources exceeding a given size <boolean> 
    --max-resource-size: Maximum size of embedded resources in MB. It applies to every fetched resource, i.e. images, fonts, stylesheets, scripts, frames, videos and audios; a resource above the limit is left out of the saved page <number> (default: 10)

  * Content Processing & Optimization:
    --compress-css: Deprecated, it has no effect <boolean> 
    --compress-html: Compress HTML content <boolean> (default: true)
    --remove-frames: Remove frames <boolean> 
    --remove-hidden-elements: Remove HTML elements which are not displayed <boolean> (default: true)
    --removed-elements-selector: Remove specific HTML elements matching the given CSS selectors (comma separated) <string> 
    --remove-unused-styles: Remove unused CSS rules and unneeded declarations <boolean> (default: true)
    --remove-unused-fonts: Remove unused CSS font rules <boolean> (default: true)
    --remove-alternative-fonts: Remove alternative fonts to the ones displayed <boolean> (default: true)
    --remove-alternative-medias: Remove alternative CSS stylesheets <boolean> (default: true)
    --remove-alternative-images: Remove images for alternative sizes of screen <boolean> (default: true)
    --remove-no-script-tags: Remove <noscript> tags <boolean> (default: true)
    --move-styles-in-head: Move style elements outside the head element into the head element <boolean> 
    --group-duplicate-images: Group duplicate images into CSS custom properties <boolean> (default: true)
    --max-size-duplicate-images: Maximum size in bytes of duplicate images stored as CSS custom properties <number> (default: 524288)
    --image-reduction-factor: Divide the dimensions of PNG, JPEG and WEBP images by this factor in order to reduce the size of the page (e.g. 2 halves them). Images whose size is not set by the page (e.g. icons, logos) are displayed smaller <number> (default: 1)
    --image-quality: Quality of the JPEG and WEBP images resized with --image-reduction-factor, between 0 and 1 (1 saves WEBP images without loss) <number> (default: 0.8)
    --group-duplicate-stylesheets: Group duplicate inline stylesheets into a single stylesheet in order to reduce the size of the page <boolean> (default: false)

  * Output & Compression:
    --compress-content: Create a ZIP file instead of an HTML file <boolean> 
    --disable-compression: Store the files of the ZIP file without compressing them <boolean> 
    --self-extracting-archive: Create a self-extracting (ZIP) HTML file <boolean> (default: true)
    --password: Password of the zip file when using --compress-content or --self-extracting-archive <string> 
    --insert-text-body: Insert the text of the page into the self-extracting HTML file <boolean> 
    --create-root-directory: Create a root directory based on the timestamp. With --crawl-save-archive it stores the first page in a folder of its own instead, like the other pages, so that no page shares the root of the archive with the files describing it <boolean> 
    --extract-data-from-page: Extract compressed data from the page instead of fetching the page in order to create universal self-extracting HTML files <boolean> (default: true)
    --prevent-appended-data: Prevent appending data after the compressed data when creating self-extracting HTML files <boolean> 
    --declare-appended-data: Declare the data appended after the compressed data as the comment of the ZIP archive, for readers rejecting undeclared trailing bytes (e.g. java.util.zip); ZIP tools then print that data when listing the archive. Has no effect when the extra data is relocated ahead of the compressed data, because nothing is appended then <boolean> 
    --max-appended-data-length: Maximum number of bytes appended after the compressed data when creating self-extracting HTML files, 16361 by default. Readers only tolerate trailing bytes as far back as their end-of-archive scan reaches (16383 bytes for libarchive, 32768 for perl Archive::Zip, 65557 for Python zipfile); the default fits the narrowest. Data over the limit is relocated ahead of the compressed data instead. Raising the limit above 65535 silently defeats --declare-appended-data: the declaration is the length of the ZIP comment, a 16-bit field, so a longer run is appended undeclared and without a warning <number> 
    --embed-screenshot: Embed a screenshot of the page as a PNG file in the compressed file (self-extracting HTML or ZIP file). When enabled, the resulting file can be read as a ZIP file or a PNG image. <boolean> 
    --embed-screenshot-options: Options passed to the CDP method `Page.captureScreenshot()` given as a JSON string (e.g. { "captureBeyondViewport": false }) <string> 
    --embedded-image: Path to a PNG image to embed in the compressed file. Unlike --embed-screenshot it is also compatible with --crawl-save-archive, where it becomes the image of the whole archive. <string> 
    --embed-pdf: Embed a PDF file in the ZIP or self-extracting file. When enabled, the resulting file can be read as a ZIP file or a PDF file. <boolean> 
    --embed-pdf-options: Options passed to the CDP method `Page.printToPDF()` given as a JSON string (e.g. { "pageRanges": "1-1", "paperWidth": 11, "paperHeight": 8.5 }) <string> 
    --embedded-pdf: Path to a PDF file to embed in the compressed file. Unlike --embed-pdf it is also compatible with --crawl-save-archive, where it becomes the PDF of the whole archive. <string> 

  * Filename & Output Location:
    --filename-template: Template used to generate the output filename (see https://github.com/gildas-lormeau/SingleFile/wiki/Template-variables-and-functions) <string> (default: "%if-empty<{page-title}|No title> ({date-locale} {time-locale}).{filename-extension}")
    --filename-conflict-action: Action when the filename is conflicting with existing one on the filesystem. The possible values are "uniquify" (default), "overwrite" and "skip" <string> (default: "uniquify")
    --filename-replacement-character: The character used for replacing invalid characters in filenames <string> (default: "_")
    --filename-replaced-character: Character to replace in filenames followed by the replacement character(s), both in a single value separated by the first space, e.g. --filename-replaced-character "> _GT_" to replace ">" with "_GT_" (repeat the option to replace multiple characters, omit the replacement to use --filename-replacement-character instead). The value can also be a JSON array, which is how to express what the space-separated form cannot, e.g. [" ", "_"] to replace spaces with underscores <string*> (default: ['~ ～', '+ ＋', '? ？', '% ％', '* ＊', ': ：', '| ｜', '" ＂', '< ＜', '> ＞', '\\ ＼', '\x00-\x1f', '\x7f'])
    --filename-max-length: Specify the maximum length of the filename <number> (default: 192)
    --filename-max-length-unit: Specify the unit of the maximum length of the filename ('bytes' or 'chars') <string> (default: "bytes")
    --replace-emojis-in-filename: Replace emojis in the filename with their unicode text representation <boolean> 
    --output-directory: Path to where to save files, this path must exist. <string> 

  * Crawling:
    --crawl-links: Crawl and save pages found via inner links <boolean> 
    --crawl-inner-links-only: Crawl pages found via inner links only if they are hosted on the same domain <boolean> (default: true)
    --crawl-no-parent: Crawl pages found via inner links only if their URLs are not parent of the URL to crawl <boolean> 
    --crawl-load-session: Name of the file of the session to load (previously saved with --crawl-save-session or --crawl-sync-session) <string> 
    --crawl-remove-url-fragment: Remove URL fragments found in links <boolean> (default: true)
    --crawl-save-session: Name of the file where to save the state of the session <string> 
    --crawl-sync-session: Name of the file where to load and save the state of the session <string> 
    --crawl-max-depth: Max depth when crawling pages found in internal and external links (0: infinite) <number> (default: 1)
    --crawl-external-links-max-depth: Max depth when crawling pages found in external links (0: infinite) <number> (default: 1)
    --crawl-replace-urls: Replace URLs of saved pages with relative paths of saved pages on the filesystem <boolean> 
    --crawl-rewrite-rule: Rewrite rule used to rewrite URLs of crawled pages <string*> 
    --crawl-save-archive: Save all the crawled pages into a single (self-extracting) ZIP file, requires --compress-content <boolean> 
    --crawl-save-archive-dedup: Deduplicate identical resources shared between pages when using --crawl-save-archive <boolean> 
    --crawl-save-archive-mark-unarchived-links: Mark links to pages not saved in the archive when using --crawl-save-archive <boolean> 
    --crawl-save-archive-page-transitions: Page transitions when navigating in the archive saved with --crawl-save-archive. The possible values are "auto" (default, i.e. transitions run when pages opt in via CSS), "fade" and "none" <string> (default: "auto")
    --crawl-save-archive-page-list: Insert the list of the crawled pages in the prelude of the archive when using --crawl-save-archive, so that indexing tools can read it without extracting the archive <boolean> 
    --crawl-save-archive-toc: Save a table of contents page into the archive when using --crawl-save-archive <boolean> 

  * Browser Customization & Scripts:
    --browser-script: Path of a script executed in the page (and all the frames) before it is loaded <string*> 
    --browser-stylesheet: Path of a stylesheet file inserted into the page (and all the frames) after it is loaded <string*> 
    --browser-cookie: Ordered list of cookie parameters separated by a comma (name,value,domain,path,expires,httpOnly,secure,sameSite,url) <string*> 
    --browser-cookies-file: Path of the cookies file formatted as a JSON file or a Netscape text file <string> 
    --user-script-enabled: Enable the event API allowing to execute scripts before the page is saved <boolean> (default: true)

  * Infobar:
    --include-infobar: Include the infobar <boolean> 
    --infobar-template: Template used to generate the infobar content (see help page of the extension for more info) <string> 
    --open-infobar: Keep the infobar open when using --include-infobar <boolean> 
    --animate-infobar: Make the infobar blink and display an expanding ring when the saved page is opened, ignored when the reader's system is set to reduce motion <boolean> (default: true)
    --infobar-position-absolute: Position the infobar absolutely (fixed otherwise) <boolean> 
    --infobar-position-top: Position the infobar at the top of the page <string> (default: "16px")
    --infobar-position-bottom: Position the infobar at the bottom of the page <string> (default: "")
    --infobar-position-right: Position the infobar at the right of the page <string> (default: "16px")
    --infobar-position-left: Position the infobar at the left of the page <string> (default: "")

  * Metadata & HTML Modifications:
    --include-bom: Include the UTF-8 BOM into the HTML page, ignored when the page is compressed unless --extract-data-from-page is disabled and no image is embedded <boolean> 
    --insert-canonical-link: Insert a <link rel=canonical> element pointing at the URL of the page, ignored when the page is not saved from an HTTP(S) URL <boolean> (default: true)
    --insert-meta-csp: Include a <meta> tag with a CSP to avoid potential requests to internet when viewing a page <boolean> (default: true)
    --insert-meta-noindex: Insert a <meta name=robots content=noindex> element, so a saved page served on a public host is not indexed. Ignored when the page already declares noindex <boolean> 
    --remove-saved-date: Remove saved date metadata in HTML header <boolean> 
    --read-maff-metadata: Read the original URL and the archive time from the index.rdf file stored next to a page extracted from a MAFF archive, and save those instead of the path and the date of the extracted copy. Fetches index.rdf next to every page saved, a request that 404s on the open web, so leave it off unless you are saving extracted MAFF pages <boolean> 
    --save-original-urls: Save the original URLS in the embedded contents <boolean> 
    --insert-single-file-comment: Insert a comment in the HTML header with the URL of the page <boolean> (default: true)
    --resolve-links: Resolve link URLs to absolute URLs <boolean> (default: true)

  * Debugging & Logging:
    --console-messages-file: Path of the file where to save the console messages in JSON format <string> 
    --debug-messages-file: Path of the file where to save the debug messages <string> 
    --errors-file: Path of the file where to save the error messages <string> 
    --errors-traces-disabled: Remove error stack traces in the error messages <boolean> (default: true)
    --dump-content: Dump the content of the processed page in the console ('true' when running in Docker) <boolean> 

  * Batch Processing & Configuration:
    --urls-file: Path to a text file containing a list of URLs (separated by a newline) to save. You can also pass the options after each URL (e.g. 'https://www.example.com --filename-template={page-title}.html') <string> 
    --max-parallel-workers: Maximum number of browsers launched in parallel when processing a list of URLs (cf --urls-file) <number> (default: 8)
    --settings-file: Path to a JSON file containing the settings exported from the web extension <string> 
    --settings-file-profile: Name of the profile to use when using --settings-file <string> (default: "default")

  * Advanced/Special Modes:
    --save-raw-page: Save the original page without interpreting it into the browser <boolean> 
    --output-json: Output the result as a JSON string containing the page and network info <boolean> 
    --dump-json: Write the same JSON as --output-json to stdout, without the page content, and leave the page file alone. Unlike --output-json the page is still written where it would have been, so the two outputs can be combined. Incompatible with --output-json, and with --dump-content unless --output is set, because both write to stdout <boolean> 
    --create-browser-profile: Path of the browser profile directory to create or update instead of saving a page. The browser is started with a visible window on the URL passed as argument, log in to the website and quit the browser to save the profile, then pass it to --browser-profile when saving pages <string> 

  * General:
    --help: Show help <boolean> 
    --version: Print the version number and exit. <boolean>
